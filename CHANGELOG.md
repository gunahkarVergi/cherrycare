# Changelog

All notable changes to this project are documented here.
Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-13
### Added
- Root `package.json` with npm workspaces (`backend`, `frontend`).
- Single lockfile, package metadata and `files` whitelists.
- Scripts for build, lint, test, packaging (`npm run package`) and version bump (`npm run release:patch`).
